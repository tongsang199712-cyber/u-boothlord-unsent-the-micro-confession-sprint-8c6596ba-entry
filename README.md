A tiny Node program that writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who the unsent message was meant for, and the message itself, typed exactly as it was never sent. The confession is about a driving test passed in March and never mentioned, because the Sunday calls it gave an excuse for were the only time Dad ever asked how he was doing.

## Run it

```sh
node main.ts
```
